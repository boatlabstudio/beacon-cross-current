Beacon has to clear three buoy gates against the current, then stop inside a narrow berth. Clearing the gates is the easy part.

GitHub code and replays → Click Boat Lab below the video, then the GitHub link under the channel name.
https://github.com/boatlabstudio/beacon-cross-current#motion-trials-02--harbor-approach

Beacon's first clean docking came on training attempt 604. The final PPO checkpoint docked successfully on all 48 fixed test starts. The end of the video shows one full test in real time. The bow camera is for viewers. The model steers using 13 numeric observations from the Unity simulator.
